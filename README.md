# cs120LabGuessingGame

## Algorithm

My proposed Algorithm:
1. The program will ask the user for their name, and store it as a string. 
2. It will greet the user, by name. 
3. A random generated number between 1 and 100 will be stored as an int.
4. A guess counter will be set to zero.  
5. The program will then ask for the user to guesss the random int.
6. The guess counter will go up by one.   
7. It will compare the random int and the user input. 
8. It will check one of two things. 
⋅⋅* If the guess matches the random int. 
⋅⋅* If the guess is higher or lower than the random int. 
9. The guess counter will go up by one.
10. One of two things happens now. 
⋅⋅* If the guess is correct, move on to the next step. 
⋅⋅* If the guess is incorrect repeat from step 5
11. Print the results of the correct number, and the amount of guesses it took. 
⋅⋅* Below 7 is "very good"
⋅⋅* 7 is "average"
⋅⋅* above 7 is "very bad"
